# LLM+RAG v1.4

1.3版本仅将自定义的embedding等方法换成LangChain的接口调用，增加了知识库适配文件

环境:python 3.10 + torch 2.6(cuda12.4)

模型：qwen3:8b + bge-m3

知识库存放在knowledge_base文件夹下，启动时会自动检测知识库是否变动，目前知识库只支持存放`.txt`,`.pdf`,`.md`,`.html`,`.pptx`,`.xlsx`,`.csv`和`.docx`文件，`'utf-8', 'utf-16', 'gbk', 'big5'`几种编码。

## 初始化知识库
embedding会占用显存资源，仅初始化知识库时使用GPU，问答时使用CPU

`python knowledge.py`
## 运行
`uvicorn main:app --host 127.0.0.1 --port 8000`

`initial_prompt.txt`存放chat的prompt，ollama的qwen3上下文为40k，但如果上下文过长会影响生成速度，建议适量即可。
Prompt加入`/no_think`可临时关闭思考链。

如果`faiss-gpu`安装失败使用
`conda install -c pytorch faiss-gpu`
